> **书籍：** *Efficient Processing of Deep Neural Networks*，Vivienne Sze、Yu-Hsin Chen、Tien-Ju Yang、Joel Emer 著，Morgan & Claypool，Synthesis Lectures on Computer Architecture。

## 一、章节目标

DNN 会根据任务呈现不同的网络形状和规模，并持续演化。本章从硬件处理的角度介绍常见网络的构成：先看层内与层间的连接属性，再拆解卷积、全连接、激活、池化和归一化等基本运算，随后讨论 CNN 及其他 DNN，最后介绍框架、预训练模型和数据集等研究资源。

深度学习领域常把网络形状和规模称作“网络架构”；为避免与硬件领域的“架构”混淆，原书倾向用“DNN 模型”描述这些网络。

理解这些结构，是把“网络名称”转化为可评估工作负载的第一步。不同连接方式和层形状会改变计算量、张量访问、数据复用、依赖关系与并行机会，也决定加速器需要提供怎样的灵活性。

## 二、层内连接属性

### 2.1 连接模式：全连接与稀疏连接

![image-20261026194534605](/assets/images/efficient_processing_dnn/image-20261026194534605.png)

衡量一层连接结构的第一个属性，是输入激活与输出激活之间的连接范围：

- **全连接属性（fully connected）**：每个输入激活都连接到每个输出激活。
- **稀疏连接属性（sparsely connected）**：每个输出只连接输入中的一部分。

稀疏连接可以是**全局连接**，即一个输入可连接到任意位置的输出；也可以是**局部连接**，即输出只读取输入中的邻域窗口。局部连接使输出只依赖一小块输入，这个窗口称为**感受野（receptive field）**。图像中的邻近像素往往相关性较强，因此卷积常采用局部连接；堆叠多层后，局部感受野可逐步覆盖更大的区域。

结构上不存在一条连接，与连接存在但训练后权重恰好为零，是两回事。后者仍然是原网络中的连接，不属于连接结构本身的稀疏。

术语上也要区分：**全连接属性**描述一种连接关系；**全连接层（FC layer）**是具体层类型。本章按作者的约定将两者区分，后续章节会沿用常见说法，有时互换使用。

### 2.2 权重共享

连接的第二个属性是权重是否共享。最一般的情形是每条连接有独立权重；若多条连接使用同一个权重值，则称为**权重共享（weight sharing）**。

卷积层（CONV）同时具有局部稀疏连接和权重共享：同一组滤波器权重会在特征图的多个空间位置重复使用。局部连接减少每个输出要读取的输入数量，权重共享减少参数量并提高权重复用率，因此卷积具有适合硬件加速的数据复用机会。

## 三、层间连接属性

### 3.1 前馈连接

若一层的输出传给后续层，就是**前馈连接（feed-forward）**。连接既可以来自紧邻的前一层，也可以跨过中间层传给更后面的层；一层的输出也可以分发给多个后续层。前馈网络按层依次计算，不保留此前输入的状态，对同一输入的输出不取决于之前处理过哪些输入。

多层感知机（MLP）由前馈全连接层组成；CNN 通常组合前馈的卷积层和全连接层。彼此独立的样本可以组成 batch 并行处理，但同一个样本的相邻层仍有先后依赖，后一层需要前一层的结果。

### 3.2 循环连接

若一层的输出反馈到自身输入，就形成**循环连接（recurrent connection）**。此时输出取决于当前输入和历史输入，网络因此具有状态或记忆，可建模序列中的长期依赖。循环神经网络（RNN）常用于语音、文本等可变长度序列。

这种反馈会增加时间方向的依赖：同一序列的 `t+1` 时刻通常要等待 `t` 时刻的输出，不能像独立样本那样任意并行。RNN 的并行范围和 CNN 等前馈网络不同，这会影响 batch 处理和硬件利用率。

## 四、常见的基本层

本章把常用层分为两类：**卷积层和全连接层**以加权求和为主，通常主导计算量、能耗和吞吐率；**激活、池化、归一化**等辅助层用于增加非线性、改变空间分辨率或改善训练。基本层可以组合为复合层；日常交流中，两类都常简称为“层”。

### 4.1 卷积层（CONV）

![image-20261026194611450](/assets/images/efficient_processing_dnn/image-20261026194611450.png)

#### 数据组织与形状参数

CNN 的输入通常是三维输入特征图（input feature map, ifmap），维度为高度、宽度和通道。一个滤波器也是三维的，空间尺寸为 `R x S`，通道数与输入特征图的 `C` 相同。滤波器在空间位置滑动，对每个通道分别执行二维卷积，再将各通道结果相加，得到一个输出通道的部分和。使用 `M` 个滤波器会产生 `M` 个输出通道；`N` 表示一次处理的输入特征图数量，即 batch size。偏置可加到滤波结果上，但一些较新的网络会在部分层省去偏置。

![image-20261026194645292](/assets/images/efficient_processing_dnn/image-20261026194645292.png)

不考虑 padding，且尺寸与步长匹配时，卷积可表示为：

```text
o[n,m,p,q] =
    sum(c=0..C-1, r=0..R-1, s=0..S-1)
      i[n,c,U*p+r,U*q+s] * f[m,c,r,s] + b[m]

P = (H - R + U) / U
Q = (W - S + U) / U
```

`i`、`f`、`o` 和 `b` 分别表示输入激活、滤波器权重、输出部分和与偏置。固定输出索引 `(n,m,p,q)` 后，要沿输入通道和滤波器空间位置 `(c,r,s)` 做点积累加。不同教材对滤波器数量的记号可能使用 `K`；本书使用 `M` 表示输出通道数。

书中的图示用**蓝色**表示输入激活、**绿色**表示权重、**红色**表示部分和。严格来说，部分和经过非线性函数后才成为输出激活；为简化表述，书中有时也把部分和数组称作输出特征图。滤波器由权重（类比突触）组成，ifmap 和 ofmap 由输入、输出激活组成。

#### 从张量运算到硬件数据流

卷积是高维张量代数运算。矩阵乘法可写成：

```text
Z[i,j] = sum(k) A[i,k] * B[k,j]
```

对应的卷积张量索引形式为：

```text
O[n,m,p,q] =
    sum(c,r,s) I[n,c,U*p+r,U*q+s] * F[m,c,r,s] + b[m]
```

求和变量的次序不改变数学结果，但会改变数据访问和计算顺序，因此会影响数据流及硬件映射。卷积的复用机会包括：同一滤波器用于多个空间位置、同一输入激活参与多个输出、输出部分和在累加期间留在近端存储，以及 batch 增加权重复用。由此可见，卷积不只是二维滑窗；它包含 batch、通道、空间和滤波器等多个循环维度，循环顺序是后续数据流设计的重要问题。

### 4.2 全连接层（FC）

![image-20261026194731063](/assets/images/efficient_processing_dnn/image-20261026194731063.png)

FC 层中，每个输出都对输入特征图的所有值加权求和，通常没有权重共享，常写成矩阵乘法：

```text
o[n,m] = sum(c,h,w) i[n,c,h,w] * f[m,c,h,w]
```

FC 可视为卷积的特例：滤波器覆盖整个输入特征图，即 `R=H`、`S=W`、`P=Q=1`、`U=1`。它因此不具备卷积的局部连接和权重共享特征。FC 的权重规模通常较大、数据复用较少，容易受内存带宽和数据移动限制，呈现 memory-bound 特征。

### 4.3 非线性激活

![image-20261026194816726](/assets/images/efficient_processing_dnn/image-20261026194816726.png)

CONV 或 FC 后通常接非线性激活，否则多层线性变换仍可合并为单个线性变换。常见函数包括 Sigmoid、Tanh、ReLU、Leaky ReLU、Parametric ReLU、ELU、Swish 和 Maxout。Sigmoid、Tanh 曾因便于数学分析而常见；ReLU 计算简单、训练较快且准确率有竞争力，因此被广泛采用。

```text
Sigmoid:      y = 1 / (1 + exp(-x))
Tanh:         y = (exp(x) - exp(-x)) / (exp(x) + exp(-x))
ReLU:         y = max(0, x)
Leaky ReLU:   y = max(a*x, x), a 为较小常数
ELU:          y = x, x >= 0; 否则 α*(exp(x)-1)
Swish:        y = x * sigmoid(a*x)
```

ReLU 会把负值变为零，增加输出激活的稀疏性。若硬件能识别并跳过零值，就有机会降低存储、数据移动和算术开销。Maxout 则取两条相交线性函数中的较大值，原书举其在语音识别中的应用。

### 4.4 池化与上采样

![image-20261026194901400](/assets/images/efficient_processing_dnn/image-20261026194901400.png)

**池化（pooling）**或下采样降低特征图空间分辨率，通常按通道独立处理，把感受野内多个值聚合为一个值。常见操作是最大池化和平均池化，典型配置为 `2 x 2` 窗口、stride 2；窗口通常不重叠，池化常位于非线性之后。它能压缩表示，并提升模型对小幅位移和局部扰动的鲁棒性。分类网络可用编码器逐步压缩图像；语义分割等密集预测任务则需要解码器恢复空间分辨率。

**上采样（upsampling）**增加特征图分辨率，也常称反池化（unpooling）。常见方式有：在激活之间插入零、最近邻插值、双线性或双三次插值。零插入是常见的反池化实现；另一种方式会在最大池化时记录最大值位置，并在上采样时把非零值放回该位置。上采样通常放在 CONV 或 FC 之前。零插入会产生规则的结构化稀疏，可供硬件跳过无效运算。

### 4.5 归一化

归一化控制层输入分布，以帮助加快训练并改善准确率。批归一化（Batch Normalization, BN）先将输入变为零均值、单位标准差，再用训练得到的缩放、偏移参数变换：

```text
y = (x - μ) / sqrt(σ^2 + ε) * γ + β
```

其中 `μ`、`σ` 描述输入分布，`γ`、`β` 为可学习参数，`ε` 用于避免数值问题。BN 通常位于 CONV/FC 与激活函数之间；局部响应归一化（LRN）通常位于激活之后。LRN 的灵感来自神经生物学中的侧向抑制，曾用于早期 CNN，如今大多由 BN 取代。推理时，若 BN 紧跟 CONV 或 FC，可将其固定参数折叠进原层权重和偏置，避免额外运算。

原书还指出，BN 加快并稳定训练的原因可能与优化景观更平滑、梯度行为更可预测有关，不宜简单归因于稳定层输入分布。

### 4.6 复合层

复合层是基本运算的常用组合：

- **Attention 层**：由矩阵乘法和前馈全连接操作构成，是 Transformer 的核心组件之一，也用于多种数据任务。
- **Up-convolution 层**：先对输入做零插入上采样，再执行卷积，常用于 Auto Encoder 和 GAN 的解码器。

分析复合层时，可以继续拆为矩阵乘法、卷积、逐元素操作和数据重排，分别评估其计算与访存成本。

## 五、卷积神经网络（CNN）

![image-20261026194929372](/assets/images/efficient_processing_dnn/image-20261026194929372.png)

### 5.1 CNN 的层级表示

CNN 由多层卷积逐步提取更高层次的特征，典型流程为：

```text
原始图像 -> 低级特征 -> 中级特征 -> 高级特征 -> 类别分数
```

CNN 也用于语音识别、游戏和机器人等领域；本书重点讨论图像处理，尤其是分类。原书所述的图像分类 CNN 从约 5 层发展到超过 1,000 个卷积层，通常在卷积层后接 1 至 3 个全连接层。网络深度增加可形成更丰富的层级表示，但也增加计算、存储和训练难度。

### 5.2 代表性 CNN 模型

下表沿用原书汇总的模型规模和 ImageNet Top-5 错误率。多裁剪一列对应竞赛时对图像多次裁剪并集成多个模型的成绩，实际要运行多次；单裁剪更接近一次推理的部署成本。错误率越低越好。

![image-20261026195000681](/assets/images/efficient_processing_dnn/image-20261026195000681.png)

LeNet 的统计会随具体版本变化：表中 60K 权重、341K MACs 对应常见版本；原书也列出一个采用 ReLU 的版本，约 431K 权重、每图 2.3M MACs。比较模型时还要留意输入尺寸、裁剪和集成方式。

- **LeNet-5**：1989 年提出，用于 `28 x 28` 灰度手写数字识别。两层 CONV 后接两层 FC；卷积使用 `5 x 5` 滤波器，通道数依次为 6 和 16，每层卷积后做 `2 x 2` 平均池化并使用 Sigmoid。它促成了 CNN 的早期商业应用，例如 ATM 支票存款数字识别。
- **AlexNet**：2012 年赢得 ImageNet Challenge，使用 5 层 CONV、3 层 FC 和 ReLU；第 1、2、5 个卷积层后采用 `3 x 3` 最大池化，首层 stride 为 4，前两层池化前曾使用 LRN。第二、第四、第五层将通道分为两组以减少权重和计算，例如第二层把首层的 96 个输出通道分成两组、每组 48 个通道。
- **OverFeat**：总体类似 AlexNet，但部分后层滤波器数更多，第二层不分组，第一 FC 层通道数较少，输入为 `231 x 231`。除 Fast 外还有 Accurate 版本；后者 Top-5 错误率再降低约 0.65 个百分点，代价是约 1.9 倍 MACs。
- **VGG**：VGG-16 用 13 层 CONV 和 3 层 FC，将较大的有效感受野拆成连续的 `3 x 3` 卷积，减少参数并增加非线性层。VGG-19 比 VGG-16 的 Top-5 错误率低约 0.1 个百分点，但 MACs 增加约 1.27 倍。
- **GoogLeNet / Inception**：V1 有 22 层，包含 3 个前置 CONV、9 个 Inception 模块（每个包含两层卷积）和 1 个 FC。模块并行使用 `1 x 1`、`3 x 3`、`5 x 5` 卷积及 `3 x 3` 最大池化，再拼接输出，以覆盖多个空间尺度。`1 x 1` 卷积建模通道相关性并压缩后续通道；全局平均池化把特征图汇总，取代部分 FC 层。V3 将较大卷积分解为 `1 x 5` 与 `5 x 1`，并结合 BN，扩展到 42 层；原书报告其 Top-5 错误率比 V1 低 3 个百分点以上，MACs 约为 2.5 倍。V4 引入残差连接，错误率进一步降低约 0.4 个百分点。
- **ResNet**：残差/跳跃/恒等连接让信息绕过若干权重层，缓解深层网络训练中的梯度消失。网络学习残差 `F(x)`，再与输入相加：

  ```text
  H(x) = F(x) + x
  ```

  瓶颈模块使用 `1 x 1 -> 3 x 3 -> 1 x 1`：先压缩通道以降低中间 `3 x 3` 的成本，再恢复输出通道。ResNet 有多种深度：18、34 层版本通常不使用瓶颈，50、101、152 层版本使用瓶颈。ResNet-50 约 25.5M 权重、3.9G MACs；ResNet-152 约 60M 权重、11.3G MACs，Top-5 错误率比 ResNet-50 低约 1 个百分点，但权重约 2.5 倍、MACs 约 2.9 倍。原书将 ResNet-152 描述为 ImageNet 冠军及 Top-5 错误率首次低于 5% 的参赛网络。

### 5.3 CNN 中的典型结构创新

![image-20261026195032552](/assets/images/efficient_processing_dnn/image-20261026195032552.png)

- **分组卷积**：把输入通道和滤波器分组，每个滤波器只连接一组输入，从而减少权重和乘法，也改变跨组数据通信模式。AlexNet 已使用分组；算法与硬件协同设计还可更积极地采用这一结构。

![image-20261026195051056](/assets/images/efficient_processing_dnn/image-20261026195051056.png)

![image-20261026195200990](/assets/images/efficient_processing_dnn/image-20261026195200990.png)

- **小滤波器分解**：连续多个 `3 x 3` 卷积可构造较大的有效感受野，相较直接用 `5 x 5` 可减少参数并增加非线性。Inception 还将 `5 x 5` 分解为连续的 `1 x 5` 与 `5 x 1`，以降低成本。

![image-20261026195222678](/assets/images/efficient_processing_dnn/image-20261026195222678.png)

- **Inception 与 `1 x 1` 瓶颈**：多分支并行处理不同尺度后拼接。`1 x 1` 卷积不建模空间邻域，但能提取通道相关性并投影、压缩通道，减少后续计算。

![image-20261026195244552](/assets/images/efficient_processing_dnn/image-20261026195244552.png)

- **残差连接**：shortcut 让输入绕过若干层后与变换结果相加，改善深层网络的信息和梯度传播，并支持训练更深模型。

- **DenseNet**：从多个前序层建立跳跃连接，强化特征传播和复用，也称特征聚合。
- **WideNet**：增加宽度（滤波器数）而非深度，通常更有利于并行。
- **ResNeXt**：增加卷积分组数，即基数（cardinality），作为深度、宽度之外的扩展方向；原书提到它参与了 2017 年 ImageNet 获胜方案。
- **EfficientNet**：协同缩放深度、宽度和输入分辨率；更高分辨率通常需要更大的感受野和更多通道来提取细节。

![image-20261026195405639](/assets/images/efficient_processing_dnn/image-20261026195405639.png)

这些变化表明，准确率并非只能靠加深网络提升；层数、层形状、宽度、分组和分辨率彼此影响。加速器需要适配不同滤波器尺寸、通道数、连接和数据流，不能只为一种固定网络定制。

### 5.4 对硬件设计的启示

1. 现代 CNN 的大部分计算已集中在 CONV，而不再主要由早期模型的大型 FC 层支配；从 GoogLeNet 起，卷积层也通常占据更多权重。
2. 全局平均池化、瓶颈和结构化设计降低了 FC 层权重规模，但卷积层形状仍然多变，硬件必须兼顾效率与灵活性。
3. 卷积的局部性和权重共享带来复用，但实际收益依赖片上存储、数据布局和数据流；只增加乘法器未必能提高实际吞吐率或能效。
4. 深度、宽度、分辨率及分组方式相互耦合。评估模型和硬件不能只看 MACs，还要考虑内存访问、并行度、输入尺寸和推理方式。

因此，面向 CNN 的设计应优先高效执行卷积，同时适配不同网络层形状。模型结构趋势也是加速器灵活性需求的依据。

## 六、其他类型的 DNN

![image-20261026195456880](/assets/images/efficient_processing_dnn/image-20261026195456880.png)

### 6.1 RNN

RNN 和 Transformer 常用于可变长度的语音、文本等序列。RNN 的权重沿时间维共享，不同深度层则使用不同权重；计算依赖同时存在于时间和网络深度方向。例如，时刻 `t` 的第 `i` 层输入依赖第 `i-1` 层在 `t` 时刻的输出，也依赖第 `i` 层在 `t-1` 时刻的状态。

因此，RNN 可并行处理彼此独立的多条序列，却不能任意并行同一序列的相邻时间步；同一输入的相邻层也仍有前馈依赖。RNN，尤其 LSTM，除矩阵乘法外还需要逐元素乘法及 Sigmoid、Tanh 等函数。原书指出这些运算通常不主导总时间或能耗，可交由软件执行，或用分段线性查找表近似非线性函数。

### 6.2 Transformer

Transformer 通过 Attention 和矩阵乘法处理序列，不依赖 RNN 的逐时间步反馈，适用于文本等可变长度数据。其矩阵乘法在数据复用不足时会像 FC 层一样受内存带宽限制。面向 FC 的分块（tiling）和剪枝等方法，也可用于 RNN 和 Transformer。

### 6.3 Auto Encoder 与 GAN

Auto Encoder（AE）和生成对抗网络（GAN）常用编码器-解码器结构：编码器通过卷积和池化压低空间分辨率，解码器通过上采样和上卷积恢复分辨率。

- AE 可用于深度估计、语义分割等逐像素预测任务。
- GAN 可用于图像合成和风格迁移。

它们的卷积计算可以利用 CNN 加速技术；解码器还需要支持上采样。零插入形成的结构化稀疏也可供硬件利用。

### 6.4 不同 DNN 的共同点

不同网络最终都可拆成卷积、矩阵乘法、逐元素运算、非线性、池化和上采样等有限的基本操作。RNN/Transformer 的矩阵乘法可借鉴 FC 优化，AE/GAN 解码器的上卷积可借鉴 CONV 优化；网络差异还体现在数据依赖和辅助计算。因此，硬件既要优化主导运算，也要支持必要的逐元素操作、非线性和张量重排。

## 七、DNN 开发资源

### 7.1 深度学习框架

开源框架简化模型开发和训练网络共享，也为硬件研究提供统一的基本运算接口与真实工作负载。原书列举的框架包括：

- **Caffe**：UC Berkeley 于 2014 年发布，支持 C、C++、Python 和 MATLAB。
- **TensorFlow**：Google 于 2015 年发布，以数据流图表达张量操作，支持 C++、Python 以及多 CPU/GPU。
- **Torch / PyTorch**：Torch 支持 C、C++、Lua；PyTorch 是其后继，以 Python 为主要接口。
- **Theano、MXNet、CNTK** 等其他框架。
- **Keras**：运行于多个底层框架之上的高层 Python 库，原书列举 TensorFlow、CNTK 和 Theano。

框架大量调用卷积、矩阵乘法等标准原语，因此能透明接入优化软件库或加速硬件，例如 GPU 上的 cuDNN，以及通过 Caffe 接入的 Eyeriss。框架还可驱动工作负载实验、性能剖析和算法-硬件权衡。以上为原书介绍的生态背景。

### 7.2 预训练模型与模型交换

公开的预训练模型可用于直接评估网络和硬件，不必每次从头训练。但同名模型的准确率也可能因训练方法和测试流程不同而相差约 1% 至 2%，因此未必与原论文数值完全一致。

不同框架之间的模型迁移曾不方便。ONNX（Open Neural Network Exchange）旨在建立开放的可交换模型生态。原书介绍时列出的参与方包括 Amazon、Facebook 和 Microsoft。

### 7.3 分类数据集

图像分类是给整张图像选择一个类别，不涉及目标定位或检测。任务越难，通常需要更复杂的模型、更多权重和 MACs，也可能增加能耗、降低吞吐率。因此，准确率必须结合数据集和任务难度解读。

#### MNIST

MNIST 于 1998 年推出，包含 `28 x 28` 灰度手写数字图像、10 个类别，训练集 60,000 张、测试集 10,000 张。原书记录 LeNet-5 早期达到 99.05% 准确率，之后使用 DropConnect 正则化的网络达到 99.79%；因此它已是相对简单的基准。

#### CIFAR-10

CIFAR 于 2009 年推出，是 Tiny Image 数据集的子集。CIFAR-10 包含 `32 x 32` 彩色图像和 10 个互斥类别，训练集 50,000 张、测试集 10,000 张。原书记录早期两层卷积深度置信网络准确率为 64.84%，之后使用 fractional max pooling 的方法达到 96.53%。这些数值来自不同方法和时期，适合作为发展背景，不代表严格同条件比较。

#### ImageNet

原书介绍的 ImageNet 分类版本包含 `256 x 256` 彩色图像和 1,000 个类别。类别依 WordNet 构建层级，对同义词作合并且类间不重叠，含有细粒度类别，例如 120 种犬类。数据集有约 130 万张训练图、10 万张测试图和 5 万张验证图。

- **Top-1**：最高分的类别必须正确。
- **Top-5**：前五个候选类别中包含正确类别即可。

原书记录：2012 年 AlexNet 的验证集 Top-5 准确率为 83.6%，当年未使用 DNN 的第二名为 73.8%；AlexNet 的 Top-1 准确率为 61.9%。书中还报告 2019 年模型 Top-5 准确率已超过 97%、Top-1 超过 84%。这些是原书的历史记录。比较模型时应同时注明数据集、准确率指标、输入分辨率和推理方式。

### 7.4 其他任务数据集

定位和检测比整图分类需要更多空间信息。ImageNet 单目标定位要求分类并给出目标边界框；目标检测则需定位、分类图中所有目标，未能对应真实目标的预测和重复检测都会受罚。其他常见数据集包括：

- **PASCAL VOC（2005-2012）**：约 11,000 张图、20 个类别、27,000 个目标实例，其中约 7,000 个带精细分割标注。
- **COCO**：约 328,000 张图、91 个类别、250 万个标注实例，支持检测、分割和上下文识别；类别少于 ImageNet，但每类实例更多、单图标注更丰富，适合精细定位和利用场景上下文。
- **Open Images**：原书所述版本有 900 多万张图，覆盖约 6,000 个类别。
- **YouTube 视频数据集**：原书所述版本包含约 800 万段视频、50 万小时内容，覆盖约 4,800 类。
- **音频事件数据集**：632 类、约 200 万条人工标注的 10 秒音频片段。

训练数据增加通常能提升准确率，原书概括这种提升近似随数据量的对数增长，并举 Google 内部 JFT-300M 为例：约 3 亿张图、18,291 类；用 50 至 80 块 GPU 对全量数据训练四轮约需两个月，说明大规模计算仍是 DNN 研究的重要瓶颈。更大数据集和新领域数据集既用于衡量准确率，也可用于刻画未来加速器的工作负载。自动驾驶等任务还可能需要高清晰度视频，低分辨率 ImageNet 并不能替代相应数据。

### 7.5 资源选择的意义

框架、预训练模型和数据集共同支持软硬件评估：框架提供可执行算子和负载，模型反映不同层形状与规模，数据集定义任务难度和输入特征。LeNet 不能代表 ImageNet 负载；单一小模型也不能代表自动驾驶视频、检测、分割或语音任务。只有使用与目标应用相符的模型和数据集，才能合理解释准确率与硬件效率。

## 八、第二章总结

本章把 DNN 拆解为连接属性、层间关系、基本计算和开发资源：

```text
层内连接：全连接 / 局部稀疏 / 权重共享
层间连接：前馈 / 循环反馈
基本运算：CONV / FC / 非线性 / 池化 / 上采样 / 归一化
网络组合：CNN / RNN / Transformer / AE / GAN
评估资源：框架 / 预训练模型 / 数据集
```

需要记住的要点：

1. 局部连接和权重共享带来复用；FC 与 Attention 的矩阵乘法通常复用较少；循环连接限制同一序列的时间并行。
2. 卷积是高维张量运算，索引维度和循环顺序会改变数据访问、数据流与硬件映射。
3. 池化、上采样、BN、残差、分组和瓶颈都会改变张量形状、稀疏性和依赖，不能只看主计算。
4. 模型规模、MACs 和准确率必须结合任务难度、输入尺寸、评估指标及单次推理方式解释。
5. 框架和模型交换生态影响加速器能否融入实际开发流程；基准测试也应采用代表真实应用的模型与数据集。

## 九、个人思考与待验证问题

1. **局部连接和权重共享怎样降低成本？**

   局部连接减少单个输出读取的输入数，权重共享减少参数存储并增加权重复用。后续阅读硬件数据流时，可观察不同设计优先将权重、输入激活还是输出部分和留在片上。

2. **为什么 FC 层容易受内存限制？**

   FC 的连接范围大，空间局部性和权重复用通常不如卷积。若权重不能及时供给计算单元，仅增加乘法器也无法充分提高吞吐率。

3. **网络越深一定越好吗？**

   深度可以丰富特征层级，也增加计算和数据移动，并可能造成梯度消失。残差连接说明结构要兼顾表达能力、可训练性和硬件代价。

4. **为什么评估加速器要使用真实模型和数据集？**

   任务的层形状、分辨率、参数量和并行度差异很大。单个小网络可能高估实际性能；只统计 MACs 也会忽略内存访问与数据布局瓶颈。

5. **基本层为何是算法与硬件之间的桥梁？**

   复杂模型可拆解为有限种算子。加速器不必针对每个高级模型名称单独设计，但需要高效支持卷积、矩阵乘法、逐元素运算、非线性、归一化、池化和张量重排，并由软件或编译器完成映射。
